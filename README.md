# linux-aws-ec2-lab
Hands-on linux practice on AWS EC2: file management, logging, and permissions (chmod)
## Goal
Learn file management, logging, file permissions, and basic monitoring on real cloud server.
## Environment
- AWS EC2 (Ubuntu), connected via EC2 Instance Connect
- Region:ap-south-1 (Mumbai)
## What I practiced

### 1. File and directory management
`mkdir` , `cd` ,`pwd` , `touch` , `echo` , `ls -l`, `cat`

### 2. Logging with redirection
- '>' overwrites a file
- '>>' appends to a file
